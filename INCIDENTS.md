# Project Incidents: Tether

Dokumen ini mencatat setiap kendala teknis, akar masalah, dan solusi yang ditemukan selama pengembangan dan audit aplikasi Tether.

| ID | Tanggal | Komponen | Deskripsi Kendala | Akar Masalah | Solusi | Status |
|---|---|---|---|---|---|---|
| INC-001 | 2026-10-30 | UI / Compose | Overdraw & frame drop pada rotasi kartu Scrapbook | `Modifier.rotate()` memicu rekomposisi penuh | Ganti dengan `Modifier.graphicsLayer { rotationZ = ... }` untuk transformasi di GPU | RESOLVED |
| INC-002 | 2026-10-30 | P2P Network | P2P failure pada Android 13+ tanpa GPS | Android 13+ mensyaratkan izin `NEARBY_WIFI_DEVICES` | Tambahkan deklarasi izin `NEARBY_WIFI_DEVICES` dengan `usesPermissionFlags="neverForLocation"` | RESOLVED |
| INC-003 | 2026-10-30 | Database | Residu data pesan sensitif di file database SQLite | SQLite standar tidak mengosongkan deleted pages | Terapkan `PRAGMA secure_delete = ON`, `PRAGMA auto_vacuum = FULL`, dan `clearPassphrase = true` pada SQLCipher | RESOLVED |
| INC-004 | 2026-10-30 | Security / P2P | Paket P2P terkirim dalam format JSON plaintext di TCP port 42890 | `SessionCryptoEngine` belum diintegrasikan ke dalam pipa socket `TetherP2pManager` | Bungkus setiap paket dengan amplop AES-256-GCM (`wrapWireEnvelope` / `unwrapWireEnvelope`) dan ikat kedua kunci publik ECDH secara deterministik di KDF | RESOLVED |
| INC-005 | 2026-10-30 | Security / Pairing | Kunci publik QR Pairing statis (`tether_ed25519_pub_key_offline`) | `PairingScreen` dan `ScrapbookVaultSheet` menggunakan string dummy | Simpan dan muat pasangan kunci identitas ECDH (`secp256r1`) terenkripsi di Android Keystore melalui `KeystoreManager.getOrCreateIdentityKeyPair` | RESOLVED |
| INC-006 | 2026-10-30 | Network / Socket | `ServerSocket.reuseAddress` tidak efektif & potensi `FAILURE_ALREADY_ACTIVE` pada NSD | `ServerSocket(port)` langsung melakukan bind sebelum `reuseAddress = true`, dan `resolveService` dipanggil paralel | Inisialisasi unbound `ServerSocket()`, set `reuseAddress = true` sebelum `bind()`, serta tambahkan guard `AtomicBoolean` pada `NsdManager.resolveService` | RESOLVED |
| INC-007 | 2026-10-30 | UI / Chat & Sync | Pesan Polaroid/Whisper pengirim tampil di sisi kiri, timestamp statis `"baru saja"`, dan Touchpad/TugBack tidak mengirim paket P2P | Alignment di-hardcode ke `CenterStart`, `localTimestamp` tidak diformat pada bubble teks, serta callback P2P belum terhubung | Gunakan alignment dinamis berbasis `senderId`, format `localTimestamp` (`HH:mm`), dan hubungkan `TouchpadScreen`, `CouponsScreen`, serta tombol `TugBack` overlay ke `ChatViewModel` | RESOLVED |
| INC-008 | 2026-10-30 | Memory / Storage | Risiko `OutOfMemoryError` dan kebocoran file saat mengganti foto profil berkali-kali | `BitmapFactory.decodeFile` dipanggil penuh di UI thread dan file avatar lama tidak dihapus | Tambahkan `BitmapLoader.decodeSampledAvatar` (`inSampleSize`), pindahkan I/O galeri ke `Dispatchers.IO`, dan bersihkan file avatar lama | RESOLVED |
| INC-009 | 2026-10-30 | Database / Progression | Kebutuhan state level keintiman pasangan & migrasi database Room SQLCipher | Skema v2 belum memiliki tabel level pasangan | Tambahkan `CoupleLevelEntity`, `CoupleLevelDao`, migrasi `Migration(2, 3)` ke `TetherDatabase`, serta akumulasi XP interaksi | RESOLVED |
| INC-010 | 2026-10-30 | AI / Design System | Karakter avatar profil terbatas pada foto statis tanpa sentuhan retro 16-bit | Belum ada generator avatar pixel art berbasis AI lokal | Integrasikan `PixelAvatarGenerator` via endpoint 9Router lokal (`ag/gemini-3.8-flash`) dengan fallback preset offline | RESOLVED |
| INC-011 | 2026-10-30 | Security & UX / Onboarding | Pengguna harus scan QR fisik untuk pairing, serta risiko penimpaan passphrase SQLCipher jika Keystore error | Alur pairing QR mengharuskan tatap muka langsung, dan `KeystoreManager` membangkitkan passphrase baru saat dekripsi gagal yang merusak DB lama | Buat alur masuk universal "Kamar Rahasia Berdua" dengan derivasi kunci AES-256 E2EE (`deriveRoomAesKey`), cegah overwrite passphrase di `KeystoreManager`, dan isolasi endpoint cloud per kamar | RESOLVED |
| INC-012 | 2026-10-30 | Performance & Architecture | Potensi OOM/jank pada ribuan pesan, database lock saat tulis, cache bitmap statis, dan race condition kripto | `getAllMessagesFlow()` memuat seluruh data ke memori, SQLite rollback journal memblokir baca, cache bitmap tidak berbasis byte nyata, dan kriptografi berjalan paralel di thread pool acak | Terapkan SQLite WAL mode (`synchronous = NORMAL`), windowing query pesan (100 pesan/media + tombol muat lama), LruCache berbasis byteCount RAM aktual, dedicated single-thread crypto dispatcher, serta protokol status ACK dua arah (`DELIVERED_ACK` + indikator centang dua `✓✓`) | RESOLVED |
| INC-013 | 2026-10-30 | Audio / Voice Note & System Audit | Tombol Voice Note (VN) belum ada di UI, rekaman audio masih mock sample, dan warning API audio terdepresiasi | Bottom bar tidak memiliki tombol rekam, izin `RECORD_AUDIO` belum terdaftar, belum ada integrasi `MediaRecorder` & `MediaPlayer` riil, dan perutean audio earpiece memakai API lama | Tambahkan izin `RECORD_AUDIO`, integrasikan tombol VN retro 16-bit dengan transisi status rekam (`MEREKAM` + titik merah berkedip, Batal, Kirim), pipeline perekaman `MediaRecorder` AAC m4a + base64 wire packaging, pemutaran riil via `MediaPlayer` tersinkronisasi `ProximitySensorManager` API 31+ modern, dan pembersihan resource di `onCleared` | RESOLVED |
